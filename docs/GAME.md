# The game

## In one breath

Three words appear. Everybody answers the same question about them. Then you
try to work out who wrote what — and the answers you get wrong are the ones
worth talking about.

## Why it is built this way

The obvious version of this game is *spot the host*: one player secretly knows
what the words mean, everyone else writes a decoy, and you hunt for the
impostor.

That version does not start conversations. In a hidden-role game the optimal
move is to **blend in** — write something plausible, unremarkable, and hard to
attribute. If the scoring rewards camouflage, players write camouflage, and a
table full of camouflage is a quiet table.

So the scoring is inverted:

> **+2 for every person who correctly identifies your answer as yours.**

Now the optimal move is to sound exactly like yourself. The most *you* answer
in the room is the highest-scoring answer in the room. Players stop hedging and
start writing the thing they'd actually say — which is the raw material of a
conversation.

The second-order effect is the good one. Once everybody is writing honestly,
the *wrong* guesses become interesting. "You thought that was me?" and "wait,
*you* wrote that?" are the two sentences the whole design is trying to produce.

## The parts

### The lobby

The host opens a room and gets a QR code plus a four-character code. Everybody
else scans, taps the shared link, or types the code — no accounts, just a name.

Each player taps **I'm ready**, and the ready dots fill in live on every screen
in the room. The host launches when they judge the room is set; the button
reads `Launch anyway (3/5)` if some people have not tapped in. The ready signal
tells the host the room is paying attention. It never blocks them.

### The deal

The dealer gets nine word tiles laid out in three rows:

| Row | Contents |
|---|---|
| Something solid | people, places, objects |
| Something that happens | moments and actions |
| Something you feel | feelings and values |

They pick any three. The rows are not a rule, they are a nudge — a trio drawn
from different rows produces a better question than three nouns in a row. The
dealer's choice is the round's fingerprint; two dealers with the same nine
tiles will build different rounds.

### The frame

Three words alone are a word-association test. A frame turns them into
something a person has an answer to:

| Frame | The question |
|---|---|
| What it brings back | What do these three words make you remember? |
| Who comes to mind | Who do these three words make you think of, and why? |
| Connect all three | Put *X*, *Y* and *Z* in one sentence. |
| Turn it into advice | Turn these three words into a piece of advice. |
| Which one is you | Which is most you right now — *X*, *Y* or *Z*? Say why. |
| Finish the thought | *"X is where I learned ______."* |

*What it brings back* and *Who comes to mind* are weighted highest because they
are the two that reliably produce stories rather than sentences.

### The permission line

Every writing screen carries one line:

> True, fictional, or somewhere in between — always allowed.

This is load-bearing, not decoration. It is what lets someone at a table with
their in-laws play a game about family without being cornered into disclosing
anything. Nobody ever has to be honest; the game only needs them to be
*characteristic*.

### The match

Each player pairs every answer with a name. A name can only sit on one card, so
with *n* players it is a genuine *n−1* way matching puzzle rather than a set of
independent guesses. Getting one right often means getting another right, which
makes the reveal cascade.

### Table talk

After scoring, the app finds the answer with the fewest correct matches — the
biggest surprise of the round — puts it full-screen with its author's name, and
says:

> **Nobody saw that coming. [Name], tell us.**

There is no timer on this screen and no scoring attached to it. The only
control is *Okay, next*, and only the dealer has it.

This is the feature the rest of the game exists to set up. Everything before it
is a machine for finding the one thing in the room most worth asking about.

### Passing the deck

By default the next dealer is whoever read the room best that round — most
correct matches. It makes dealing feel earned, and it hands control to the
person currently most tuned in to the table. Clockwise and random are also
available.

Nobody deals twice in a row while an alternative exists.

### The final word

Superlatives come from real activity, not from the points table:

- **Easiest to Read** — most often correctly identified
- **Total Mystery** — least often
- **Knows Everyone** — most correct matches across the night
- **Most Loved Answer** — most hearts
- **Funniest Connection** — most laughs
- **Biggest Surprise** — the answer nobody pinned, quoted in full

The points winner is shown. It is deliberately not the last thing on screen.

## Player count

| Players | Notes |
|---|---|
| 3 | Works. Two cards to match, fast rounds. |
| 4–6 | The sweet spot. |
| 7–10 | Matching gets genuinely hard; consider 3 rounds instead of 5. |

Max recognized points per round scale with the table, so a big room is not
slower to score than a small one.

## Timing

| | |
|---|---|
| Writing | 45 / 60 / 90 seconds, host's choice (default 60) |
| A round | roughly 3–4 minutes plus however long table talk runs |
| A game | 3, 5, or 7 rounds |

Table talk is deliberately unbounded. If a round takes twelve minutes because
somebody told a long story, the game worked.

## What this game is not

It is not trivia — there is no correct answer. It is not a personality test —
nothing is being measured about you. It is not a confession game — every prompt
can be answered with fiction.

It is a structured excuse to find out how the people you already know think.
